# Week 02 - Linux & Git

## 학습 내용
- WSL2와 Ubuntu 실습 환경 구축
- Linux 기본 명령어 학습
- 파일 및 디렉터리 관리
- Git을 이용한 버전 관리
- GitHub 저장소 생성 및 업로드

## 주요 명령어
- pwd : 현재 디렉터리 확인
- ls : 파일 및 디렉터리 목록 확인
- cd : 디렉터리 이동
- mkdir : 디렉터리 생성
- touch : 파일 생성
- chmod : 파일 권한 변경
- git init : Git 저장소 생성
- git add : 변경 파일 등록
- git commit : 변경 내용 저장
- git push : GitHub에 업로드
