# Week 04 - Automation & Network

## 학습 내용
- 반복문과 조건문을 활용한 작업 자동화
- 파일 검색과 로그 분석
- Git 브랜치 및 Pull Request 협업
- IP 주소, 포트, DNS의 개념 이해
- Python을 이용한 웹 서버 실행 및 네트워크 확인

## 주요 명령어
- find : 파일 및 디렉터리 검색
- grep : 특정 문자열 검색
- wc -l : 줄 수 확인
- git switch : 브랜치 이동
- git merge : 브랜치 병합
- ip addr : IP 주소 확인
- ping : 네트워크 연결 확인
- curl : HTTP 요청 및 응답 확인
- dig : DNS 조회
- ss : 네트워크 포트 상태 확인
- python3 -m http.server 8080 : 웹 서버 실행
