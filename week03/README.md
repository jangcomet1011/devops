# Week 03 - Shell Scripting

## 학습 내용
- 셸 스크립트의 개념과 자동화 필요성 이해
- 셸 스크립트 작성 및 실행
- 실행 권한과 환경 변수 설정
- 조건문을 이용한 실행 환경 점검
- Ollama와 Qwen을 이용한 로컬 AI 서비스 실행

## 주요 명령어
- nano : 파일 작성 및 수정
- chmod u+x : 스크립트 실행 권한 부여
- ./start.sh : 셸 스크립트 실행
- echo : 문자열 및 변수 출력
- export : 환경 변수 설정
- ollama serve : Ollama 서버 실행
- ollama pull : AI 모델 다운로드
